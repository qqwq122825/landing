# 应用名称与图标插槽

日期：2026-09-21。

## 用户行为

- 名称与图标分别可选：有项目值则覆盖，空值回退当前模板默认。
- 名称留空时，Feiyue 使用 ReelShort，DPTV 使用 DPTV；内部项目名称继续必填，和应用名分开。
- 图标上传后同步替换全部已标记品牌图片与 favicon；子后台、总站详情均有“恢复模板默认图标”。未选择新文件会保留已保存图标，勾选恢复并保存才清空。
- Feiyue 图片字标也接入：自定义名字显示为文字；清空名字恢复原结构，其内部品牌图片按独立图标配置处理。剧图、功能按钮和商店图标不替换。
- 项目预览带项目品牌；空名称按预览目标模板回退。全局预览只用模板默认品牌。
- 原有客户配置保留，不需要重装、删安装锁或迁移数据库。

## 实现范围

- 公共脚本使用显式 `data-hub-name` / `data-hub-logo` / `data-hub-wordmark`，替代文件名、alt 猜测。
- DPTV 5 个品牌图片位置：手机导航、桌面导航、手机侧栏、页脚、下载弹窗；另含 favicon。
- Feiyue 4 张品牌图片：导航图标、导航字标、桌面页脚字标、手机页脚字标；另含 favicon。
- 支持更新 / 恢复图标属性、picture/srcset、延迟加载源、背景图片，以及后插入的带标记节点。空插槽保留模板原有延迟加载行为。
- 名称使用 textContent，图片继续使用既有 PNG/JPG/WebP 校验和 200 KB 上限；全局和跨项目隔离保持。
- 修复长名称挤出 Feiyue 导航、DPTV 正文和下载弹窗的问题；新增模板接入规则已写入 AI 规范。
