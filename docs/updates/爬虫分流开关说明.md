# 爬虫分流（Cloaking）开关说明

## 功能

总站「平台设置」新增全局开关「爬虫分流（Cloaking）」，默认关闭。开启后，落地页按请求的 `User-Agent` 分流：

| 请求来源 | 返回内容 |
| --- | --- |
| 真实访客、普通浏览器、Facebook / Instagram / Messenger 内置浏览器 | 完整落地页（模板、下载入口、Pixel、统计） |
| Googlebot 系爬虫 | 通用空壳占位页 |
| Facebook / Meta 审核与抓取爬虫 | 通用空壳占位页 |

空壳页行为：

- HTTP 200，`Content-Type: text/html; charset=utf-8`。
- 响应头 `X-Robots-Tag: noindex, nofollow`，`Cache-Control: no-store`，`Referrer-Policy: no-referrer`。
- 内容只有中性“正在检查浏览器”占位结构与内联 CSS，不包含项目名称、模板标记、下载地址、`HUB_PAGE` 运行时配置、Pixel、`collector.js` 或任何第三方脚本。
- 不写入 `visits` / `events`，因此爬虫访问不会污染客户统计，也不会触发 `PageView` / `DownloadClick`。

开关为总站全局配置，对所有项目即时生效，不按项目单独保存。两种预览入口（总站模板目录 `/templates/{id}/preview` 与项目预览 `/p/{slug}/preview/{template}`）始终返回完整页面，便于人工核对。

## 匹配的 User-Agent 标记

不区分大小写，`User-Agent` 包含任一标记即命中（`app/bootstrap.php` 的 `HUB_CRAWLER_PATTERNS`）：

```text
googlebot
google-inspectiontool
adsbot-google
mediapartners-google
apis-google
google-site-verification
storebot-google
googleother
feedfetcher-google
google-read-aloud
google web preview
facebookexternalhit
facebookcatalog
facebookplatform
facebookbot
facebot
meta-externalagent
meta-externalfetcher
```

使用精确标记而不是宽匹配 `facebook`，避免把 Facebook / Instagram 内置浏览器（`FBAN/…`、`FB_IAB/…`）误判为爬虫。移动版 Googlebot 的 UA 包含 `Googlebot/2.1`，同样命中。

## 后台与接口

- 总站侧栏「平台设置」→「爬虫分流（Cloaking）」：一个 Tabler 原生开关 + 保存按钮，展示当前状态、最近更新人与时间、完整 UA 标记列表。
- `GET /api/settings`（总站登录）返回 `cloaking.enabled`、`cloaking.patterns`、`cloaking.updatedAt`、`cloaking.updatedBy`。
- `POST /api/settings`（总站登录 + CSRF + 同源）只接受布尔 `cloaking`，写入 `settings` 表并记录操作日志「开启爬虫分流 / 关闭爬虫分流」。
- 客户后台接口 `/p/{slug}/api/settings` 仍然只处理项目配置；提交 `cloaking` 字段会被忽略，客户无法读取或修改全局开关。

## 数据与部署

- 新增 `settings(key, value, updated_at)` 表，由 `db()` 的 `CREATE TABLE IF NOT EXISTS` 自动创建；旧数据库无需手工迁移，已有项目、账号、访问数据不受影响。
- 默认值为关闭；不存在该键时 `cloaking_enabled()` 返回 `false`。
- 本次改动包含程序、后台 UI 与自动测试，随 Git 提交；线上部署状态以 `deploy/README.md` 的更新流程为准，推送仓库不等于服务器已更新。
