## 入口与功能

总站登录后，点击左侧「模板管理」。

- 集中显示现有全部模板：Feiyue / ReelShort、DPTV / MinuteDrama。
- 支持按模板名称、品牌或编号搜索；没有结果时显示提示。
- 点击「预览模板」打开实际页面，可切换手机 / 桌面尺寸。此处仅预览，不展示「使用此模板」按钮，也不切换任何客户模板。
- 预览独立于项目，即使尚未开户也可查看；使用模板原始名称与图标，不加载客户 Pixel、不生成有效统计令牌、不创建账号或写入访问数据。
- 每款模板显示当前使用项目数与已开放账号数，统计包含已暂停项目。
- 「查看关联项目」列出当前使用或已开放该模板的项目，显示客户账号、状态、模板关系。点击「管理」进入对应项目，按原有流程调整开放范围或切换模板。
- 子账号仍使用原来的独立后台，只能预览和使用已开放模板；全局模板目录和预览需要总站身份。

本次管理范围为浏览、预览及关联项目管理；未新增模板上传、源代码编辑或删除入口。

## 更新方式

1. 先备份代码与完整私有数据目录。
2. 将「总站_模板管理更新补丁.zip」解压到总站程序根目录（有 `app`、`public`、`runtime` 的这一层），覆盖同名文件。
3. 保留 `runtime`、数据库、密钥与 `install.lock`，无需重新安装、删锁或修改伪静态。
4. 刷新后台。CSS / JS 地址会自动使用新的内容哈希；使用特殊缓存策略或关闭 OPcache 时间检查的部署，请刷新相关缓存 / PHP 服务。

补丁包含之前的账号交付与模板权限更新所需文件。此次模板管理本身没有新增数据库字段，也不修改原项目、账号密码、下载地址或模板授权。

本地 87 项自动测试通过，另以浏览器验证两款模板真实预览、手机 / 桌面尺寸、搜索与空状态、关联项目跳转、原项目预览按钮及 390px 布局。线上需上传覆盖后生效。
