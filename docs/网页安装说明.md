# 总站网页安装 / 账号初始化

## 当前推荐流程

先按 [Git 部署指南](../deploy/README.md) 克隆代码、设置 `public/` 运行目录、PHP 与私有数据权限，再打开本域名 `/install.php`。日常 Git 更新保留安装锁，不必重新安装；下方覆盖补丁步骤仅保留给旧包部署追溯。

## 旧包部署安装记录（ld.jk92.cc）

1. 先在宝塔备份现有站点文件和数据目录。
2. 将 `总站_网页安装补丁.zip` 解压后的内容覆盖到服务器 **原总站程序目录**，使 `app` 覆盖 `app`、`public` 覆盖 `public`。保留服务器已有的 `runtime`。补丁中没有数据库、锁文件或用户数据。
3. 网站运行目录仍设为总站里的 `public`，PHP 开启 `pdo_sqlite` 和 `mbstring`。允许 PHP 进程用户读写 `runtime`（或服务器配置的 `HUB_DATA_DIR`）；避免全站 777 权限。
4. 打开 [网页安装页](https://ld.jk92.cc/install.php)。此链接在上传新版文件之后生效。
5. 默认账号 **mtx**、默认密码 **mtx123**。可以在安装表单修改，正式上线推荐长随机密码；自定义密码至少 12 字节。两次密码保持一致，并勾选安装确认。
6. 若检测到已有管理员，还需勾选“保留数据并更新管理员”。这会更新主管理员的账号及密码，让旧总站会话失效，保留客户账号、项目配置、下载地址与访问统计。
7. 点击安装，看到“总站已安装完成”后，点击进入总站登录。页面不会再显示明文密码，请保存自己设置的密码。

## 锁文件在哪里

默认：**总站程序目录 → runtime → install.lock**。

如果服务器配置了 `HUB_DATA_DIR`，锁文件在那个数据目录内。锁位于公开网站目录之外，浏览器不会下载到它。

- 安装成功自动创建锁。锁存在时，GET 和 POST 安装请求均被拦截，显示“安装入口已锁定”。
- 再次安装：到宝塔文件管理中**手动删除 install.lock**，再刷新安装页。
- 保留 `hub.sqlite`、`secret.key` 和 `backups` 文件夹。删除锁不等于删除数据库。
- 删锁会重新开放安装入口，请在维护窗口操作并及时完成安装。安装完成后自动重新锁定。
- 重装前会自动在数据目录的 `backups` 文件夹创建 `before-install-*.sqlite` 数据库快照；失败则回滚管理员变更。
- 没有远程删锁按钮、URL 参数或特殊密码。

## 伪静态

宝塔 Nginx 的伪静态可使用更新后的 `deploy/nginx-rewrite.conf`：

```nginx
location / {
    try_files $uri /index.php$is_args$args;
}
location = /install.php {
    rewrite ^ /index.php last;
}
```

Apache 已有 `public/.htaccess`。本地开发的 `router.php` 同时支持 `/install` 和 `/install.php`。

## 常见问题

- **安装页 404**：检查补丁的 `public/install.php` 是否上传到了当前站点的运行目录；仅放行 index.php 的 Nginx 配置需要上面的安装路径规则。
- **PHP / 扩展未就绪**：在宝塔中启用该站点所用 PHP 版本的 `pdo_sqlite` 和 `mbstring` 后重载 PHP。
- **数据目录权限错误**：确认 PHP-FPM 的运行用户拥有数据目录及原数据库文件的读写权限。网页安装沿用服务器配置的 `HUB_DATA_DIR`，避免安装到另一个数据库。
- **请从本站页面操作**：使用 HTTPS，并确保配置中的 `HUB_ORIGIN` 是当前域名（本例 `https://ld.jk92.cc`），不带 `/public` 或其他路径。
- **安装页已过期**：刷新安装页后再提交。
- **安装入口已锁定**：说明存在 install.lock。已有账号直接返回总站登录；只有确实要重装或恢复主管理员时才手动删锁。

这次补丁仅增加网页安装能力和明确的未安装提示；不会自动给已有项目填入 APK 下载地址，也不会将本机数据上传到线上。

新版本客户交付密码使用 OpenSSL AES-256-GCM 加密。请完整保留私有数据目录的 `credentials.key`，与数据库分开备份，勿上传到公开目录。代码更新无需重新安装。
